# Bank Account Management System

## Project Description
The Bank Account Management System is a console-based Java application developed as part of the IncodeVision Internship – Task 01.

It allows users to create bank accounts and perform basic banking operations.

## Features
- Create a new bank account
- Deposit money
- Withdraw money
- Check account balance
- View all registered accounts
- View transaction history
- Validate account numbers and transaction amounts
- Prevent withdrawals when the balance is insufficient

## Technologies Used
- Java
- Object-Oriented Programming
- ArrayList
- HashMap
- Scanner
- VS Code

## Project Structure
```text
BankAccountManagement/
├── BankAccount.java
├── Main.java
```

## How to Run

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

```bash
javac BankAccount.java Main.java
```

5. Run the application:

```bash
java Main
```
